# Entscheidungen

Hier steht, **warum** das Projekt so ist, wie es ist. Jede wichtige Entscheidung bekommt eine eigene, nummerierte Notiz (in der Fachsprache: *Architecture Decision Record*, kurz ADR).

Aufbau einer Notiz:
- **Kontext** – Welches Problem, welche Situation?
- **Entscheidung** – Was haben wir beschlossen?
- **Konsequenzen** – Was folgt daraus, positiv wie negativ?

Entscheidungen werden nicht gelöscht. Ändert sich etwas, kommt eine neue Notiz, die die alte ablöst.
